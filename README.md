# UnderWraps

A secure internet communication app with email sign-in, encrypted messaging, and a strict 30MB file size limit for lightweight, private sharing.

## Features
* **Email Authentication:** Secure account creation and login flow.
* **Encrypted Chat:** End-to-end encryption for all text messages sent over the internet.
* **Capped File Sharing:** Strict server-side and client-side validation ensuring no file exceeds the 30MB limit.
* **Real-Time Delivery:** Instant, secure message and payload routing.

## Prerequisites
* Node.js (v18+)
* npm or yarn
* Your preferred database (e.g., PostgreSQL, MongoDB)
